# S00 Scene Test Assets

The S00 Bedrock fixtures are project-owned deterministic data generated by
`tools/scene_tests/generate_s00_bedrock_fixtures.py` with seed `20260731`.
They are licensed under Apache-2.0 with this repository. The generated JSON is
not copied from Blockbench, Minecraft, or any user model.

`fixture_manifest.json` is the authority for schema, role, bone/cube counts,
byte length, and SHA-256. Gate runs generate the files below
`artifacts/scene_stage_S00/generated_fixtures/` and verify the manifest before
the application sees them.

Private local models may be used only to reproduce a user report. They are not
portable gate assets, are not copied into this directory, and must never be
staged or published.

Generator v2 adds a project-owned 144-bone/10,368-Cube density fixture matching
the count profile of the user's local S00-A reproducer without copying its
geometry, names, UVs, transforms, or any other source content.

The user-supplied PT visibility screenshot is evidence rather than an input
fixture. Its inventory entry belongs under `artifacts/scene_stage_S00/evidence/`.
